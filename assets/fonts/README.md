# Bundled typefaces

The PDF generator uses two open-source typeface families from the Google Fonts repository:

- **Plus Jakarta Sans** — Regular, Medium, SemiBold, and Bold static instances generated from `PlusJakartaSans[wght].ttf`.
- **Fraunces** — a SemiBold display instance generated from `Fraunces[SOFT,WONK,opsz,wght].ttf` for editorial headings.

Both families are distributed under the SIL Open Font License 1.1. Their license texts are included beside the font files.
